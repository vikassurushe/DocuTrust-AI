# Technical notes for the team

## What to demonstrate
1. Start the Streamlit app.
2. Upload both synthetic sample files from `sample_data/`.
3. Show the extracted fields for each document.
4. Show the address mismatch finding and source filenames.
5. Add analyst review notes.
6. Download and open the PDF dossier.
7. Explain the limitations honestly.

## What not to claim
Do not claim that the prototype:
- confirms fraud,
- detects all image tampering,
- verifies signatures,
- performs handwriting recognition,
- uses an LLM or trained fraud model,
- runs live integrations that are not present.

## Before final hackathon submission
- Replace team placeholders in README and slides.
- Test on the organizer-authorized sample documents.
- Capture screenshots of the real running application.
- Record a screen-and-voice demo of the working prototype.
- Add only capabilities that have actually been implemented and tested.
